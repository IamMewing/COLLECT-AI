# All packages below are pinned to EXACT versions that are already
# installed, tested (105 passing tests), and smoke-tested live in this
# project — not loose ranges. This isn't just tidiness: an unpinned
# `pip install` resolves against whatever is newest *at build time*, and on
# 2026-11-06 that silently broke the Cloud Build deploy. `paypal-agent-toolkit`
# (below) went from a 3-dependency package at 1.1.0 to one that hard-requires
# `langchain==0.3.23`, `crewai-tools==0.13.2`, and `openai-agents==0.0.2` as of
# 1.11.0 — none of which this project uses (we only call
# `paypal_agent_toolkit.shared.api`/`.shared.configuration`, see
# agent/tools/paypal_tools.py) — and crewai-tools' own sprawling dependency
# tree (chromadb, fastapi, slack-bolt, pulsar-client, opentelemetry...) sent
# pip's resolver into an hour-long backtracking search for a mutually
# compatible set that Cloud Build gave up on (TIMEOUT / context deadline
# exceeded). Exact pins mean pip installs precisely this, no resolving.
# Re-verify deliberately (not by just bumping a `>=`) before raising any of
# these.
strands-agents==1.63.0
strands-agents-tools==0.8.12
anthropic==2.4.0
google-genai==2.34.0
pydantic==2.13.5
